# Homebrew Castov Tap 🍺

Official Homebrew tap for [Castov](https://castov.com) developer utilities and CLI.

## Installation

```bash
brew tap castovdev/castov
brew install castov
```

Or install in a single step:

```bash
brew install castovdev/castov/castov
```

## Quick Verification

```bash
castov --version
castov uuid -n 3 --v7
castov cidr 192.168.1.0/24
```

## Documentation

Visit [castov.com/cli](https://castov.com/cli) for full usage instructions.
