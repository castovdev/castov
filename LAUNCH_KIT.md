## 4. خطوات رفع إضافة VS Code لمتجر Visual Studio Marketplace

ملف الإضافة جاهز على جهازك في المسار:
`E:\time\packages\castov-vscode\castov-vscode-0.1.0.vsix`

### خطوات النشر في 3 دقائق:
1. اذهب إلى الرابط: **[marketplace.visualstudio.com/manage](https://marketplace.visualstudio.com/manage)**
2. سجل الدخول بحساب Microsoft أو GitHub.
3. اضغط على **"Create Publisher"** واكتب الاسم: `castov`.
4. اضغط على **"New Extension" -> "Visual Studio Code"**.
5. اسحب وأفلت الملف `castov-vscode-0.1.0.vsix`.
6. اضغط **Upload** وسيتم فحص الإضافة ونشرها عالمياً لملايين المبرمجين خلال دقيقتين!
